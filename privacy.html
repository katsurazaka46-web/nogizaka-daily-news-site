プライバシーポリシー

乃木坂デイリーニュース 投稿ツール（以下「本アプリ」）は、運営者が自分の YouTube チャンネル「乃木坂デイリーニュース」に動画を自動投稿するためだけに使用する個人用ツールです。

取得する情報

運営者自身の YouTube アカウントへの動画アップロード権限と、チャンネル名を確認するための読み取り権限のみです。

利用目的

運営者のチャンネルへの動画・サムネイルの投稿に使います。

保存と第三者提供

認証情報は運営者の PC 内にのみ保存し、第三者に提供しません。

運営者以外のユーザー

本アプリは運営者以外のユーザーのデータを取得・利用しません。

YouTube API サービス

本アプリは YouTube API サービスを使用しています。
